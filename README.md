# Personal Website Redesign

## Description
A simple personal website with About, Projects and Contact sections. I redesigned it to use semantic HTML and responsive CSS so it works on mobile, tablet and desktop screens.

## Technologies Used
- HTML5
- CSS3
- Git and GitHub

## Folder Structure
```
personal-website/
├── index.html
├── README.md
├── css/
│   └── style.css
└── images/
    └── profile.svg
```

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Redesign Changes
- Replaced generic `<div>` elements with `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` and `<footer>`.
- Added responsive CSS for mobile, tablet and desktop using media queries.
- Moved the CSS into a `css/` folder and the images into an `images/` folder.
- Added one local image and one online image, both with alt text.
- Added comments in the HTML and CSS to explain each part.

## Reflection
For this assignment, I redesigned my personal website using HTML, CSS and GitHub. I replaced plain div elements with semantic tags like header, nav, main, section and footer. This made my code easier to read and understand. I also learned how to make a website responsive by using media queries, so it looks good on mobile, tablet and desktop screens. Organizing my files into css and images folders kept the project neat. The biggest challenge was making the navigation work well on small screens, but using flexbox solved the problem. Working with Git branches was also new to me. Creating a separate branch let me make changes without breaking the main version of my site. Making small commits with clear messages helped me track my progress. Opening a Pull Request taught me how developers review changes before merging them. Overall, I now feel more confident using HTML, CSS and GitHub, and I want to keep improving this website by adding more projects.
